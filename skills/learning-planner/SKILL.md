# Learning Planner

## Purpose

Turn an official exam blueprint into a practical, interactive study sequence.

## Required process

1. Load the selected certification pack.
2. Load the learner profile or infer only the minimum needed from the conversation.
3. Map existing experience to certification topics.
4. Separate prerequisites, core domains, integrated scenarios, and mock exams.
5. Allocate attention according to domain weight and learner weakness, not weight alone.
6. Add hands-on exercises where implementation knowledge is expected.
7. Define stage completion checks.

## Default stages

1. Orientation and baseline assessment
2. Shared foundations and terminology
3. Domain-by-domain instruction
4. Cross-service or cross-concept comparisons
5. Integrated scenarios
6. Weakness repair
7. Timed mixed quizzes
8. Full mock exams and final readiness review

Certification packs may alter this structure.

## Progress reporting

When enabled, every lesson must show overall progress, current stage, completed topics, and remaining topics. Percentages must derive from completed learning objectives rather than elapsed time.
