# Certification Selector

## Purpose

Recommend one primary AWS certification and, when useful, one later progression target. Do not optimize for collecting many entry-level badges.

## Inputs

- current role and target role;
- cloud and IT experience;
- hands-on AWS exposure;
- technical versus business focus;
- preferred learning time and urgency;
- certifications already held.

## Required process

1. Read `certifications/registry.yaml`.
2. Verify that the recommended certification is active.
3. Compare the learner's target role with the certification's role focus.
4. Explain the expected depth and recommended experience.
5. State whether another certificate is a prerequisite. Do not invent prerequisites.
6. Recommend hands-on projects that would make the credential credible.

## Output

- primary recommendation;
- rationale;
- readiness gaps;
- optional next certification;
- what not to prioritize and why.
