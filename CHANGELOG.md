# Changelog

All notable framework changes are documented here.

## 0.2.0 - 2026-07-30

### Added

- Structured curriculum, lesson, and adaptive progress schemas.
- Curriculum-driven learning objectives, stages, modules, prerequisites, and mastery evidence.
- Reusable lesson-author skill and five approved lesson blueprints.
- Adaptive progress example and contributor templates.
- Developer Associate (DVA-C02) and Data Engineer Associate (DEA-C01) reference packs.
- Curriculum and lesson validation, cross-reference checks, and progress validation.
- Lesson-authoring and progress-model documentation.

### Changed

- Learning planner, tutor, progress coach, and agent load order now use structured curricula.
- Existing CLF-C02, AIF-C01, and SAA-C03 packs now reference versioned curricula.
- Project package version updated to 0.2.0.

## 0.1.0 - 2026-07-30

- Initial conversational skill framework, registry, three reference packs, question schema, validator, tests, and CI.
